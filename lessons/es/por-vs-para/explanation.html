¡Hola! 🦉 A diferença entre POR e PARA é o segredo para falar espanhol com naturalidade! Lembre-se: POR olha para a causa/origem, enquanto PARA olha para a finalidade/destino!

Por vs. Para em Espanhol

Domine os 4 pilares de cada preposição e nunca mais confunda em conversas.

🔄

1. Usos Fundamentais de POR (Motivo, Meio & Passagem)

Usamos POR quando a ação é motivada por algo que veio antes ou pelo meio/trajeto utilizado:

  • Motivo / Causa / Agradecimento: Gracias por invitarme. (Obrigado por me convidar).
  • Meio de transporte ou comunicação: Hablamos por teléfono / Envié la carta por correo.
  • Passagem / Trajeto: Caminamos por la playa. (Caminhamos pela praia).
  • Troca ou Valor: Lo compré por 20 euros. (Comprei por 20 euros).
  • Partes do dia: Por la mañana, por la tarde, por la noche.
"Te llamo por teléfono por la tarde."
Ligo para você por telefone à tarde.
🎯

2. Usos Fundamentais de PARA (Finalidade, Destino & Prazo)

Usamos PARA quando a ação tem um objetivo futuro, um destino final ou um prazo definido:

  • Finalidade / Objetivo (+ Infinitivo): Estudio para aprobar el examen. (Estudo para passar no exame).
  • Destinatário da ação: Este regalo es para ti. (Este presente é para você).
  • Destino físico / Direção final: El tren sale para Barcelona. (O trem parte para Barcelona).
  • Prazo / Data limite (Deadline): El proyecto es para el lunes. (O projeto é para segunda-feira).
  • Opinião pessoal: Para mí, el español es muy bonito. (Para mim, o espanhol é muito bonito).
"Compré estas flores para mi madre."
Comprei estas flores para minha mãe.
⚖️

3. Comparação Direta: A Mudança de Sentido

Veja como a escolha da preposição altera completamente o significado da frase:

Trabajo POR mi familia.
Trabalho por causa/em benefício da minha família (motivo).
Trabajo PARA una empresa española.
Trabalho para uma empresa espanhola (empregador / destinatário).
